# Skybound Showdown

Skybound Showdown is a 3D platform adventure built with Godot. Race across five sky-island courses, collect every coin, activate the course switch, and reach the finish flag. Courses add falling platforms, anti-gravity zones, and a short time-freeze ability.

## Run the game

Open `project.godot` in Godot 4.7 or later and press **F6** or **F5**. The game opens at the home screen.

## Controls

| Action | Keyboard |
| --- | --- |
| Move | W, A, S, D |
| Jump / double jump | Space |
| Freeze time briefly | F |
| Activate a nearby switch | E |
| Rotate camera | Arrow keys |
| Zoom camera | + / - |
| Return to home screen | Esc |
